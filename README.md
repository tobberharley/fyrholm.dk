# Ejerforeningen Fyrholm

Officiel GitHub Pages hjemmeside for **Ejerforeningen Fyrholm**.

## Indhold

- Velkomsttekst og kort introduktion til foreningen
- Nyheder og meddelelser fra bestyrelsen
- Downloadsektion til vedtægter, budget, regnskab m.m.
- Bestyrelsesside med kontaktoplysninger
- Kontaktformular

## Teknologi

Ren HTML5 + CSS3 – ingen build-trin, ingen afhængigheder.
Siden hostes via [GitHub Pages](https://pages.github.com/).

## Lokal forhåndsvisning

```bash
# Åbn blot index.html i en browser, eller brug f.eks.:
npx serve .
```

## GitHub Pages opsætning

1. Gå til **Settings → Pages** i dette repository.
2. Vælg **Source: Deploy from a branch** → branch `main` → folder `/ (root)`.
3. Klik **Save** – siden er live på `https://tobberharley.github.io/fyrholm/` inden for få minutter.
