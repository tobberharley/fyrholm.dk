# Dokumenter (PDF'er)

Denne mappe indeholder PDF-dokumenter der vises på `/dokumenter`.

Filerne refereres af markdown-filerne i `src/content/documents/` via deres `file:` felt.

**OBS**: Bestyrelsesreferater må IKKE lægges her — alt i `public/` er offentligt tilgængeligt på sitet.

## Filer der bruges af de forudfyldte dokument-eksempler

- `husorden.pdf`
- `vedtaegter.pdf`
- `2025-indkaldelse.pdf`
- `2025-referat.pdf`
- `2024-regnskab.pdf`

Læg de rigtige PDF-filer her med præcis disse navne, eller redigér markdown-filerne i `src/content/documents/` til at pege på dine egne filnavne.
